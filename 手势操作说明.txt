# 手势选择功能说明

## ✅ 已实现功能

答题页面现已支持完整的手势交互功能！用户可以通过手势完成所有操作。

## 🖐️ 手势操作指南

### 在答题页面（quiz.html 和 review.html）

#### 1. **选择答案**
- **👆 捏合手势** - 选择当前高亮的选项
  - 当没有选项被选中时，捏合会选择第一个选项
  - 配合手掌切换使用效果更佳

#### 2. **切换选项**
- **🖐️ 张开手掌** - 循环切换选项
  - 每次切换会高亮下一个选项
  - 自动播放音效提示
  - 循环：A → B → C → D → A...

#### 3. **确认选择**
- **✊ 握拳手势** - 确认当前选择并提交答案
  - 当有选项被高亮时，握拳提交答案
  - 提交后显示正确/错误反馈

### 在模式选择页面（quiz.html）

#### 选择练习模式
- **🖐️ 手掌悬停** - 将手悬停在卡片上方选择模式
  - 新题练习
  - 错题巩固  
  - 全部题目
- **👆 捏合确认** - 捏合手势确认选择

## 💡 使用流程示例

### 场景 1：新题练习
1. 进入 quiz.html
2. 手掌悬停在"新题练习"卡片上（高亮边框）
3. 捏合确认选择
4. 开始答题
5. 看到题目后：
   - 张开手掌循环切换选项（A→B→C→D）
   - 选中想要的选项后，捏合或握拳确认
6. 查看反馈和解析
7. 点击下一题继续

### 场景 2：错题复习
1. 进入 review.html
2. 查看错题列表
3. 点击"开始复习"
4. 使用手势答题（同场景 1）
5. 完成后查看统计结果

## 🎯 手势提示

系统会在适当时机显示手势提示：
- 开始答题时："👆 捏合选择 | 🖐️ 切换选项 | ✊ 确认"
- 模式选择时："🖐️ 手掌悬停选择模式 | 👆 捏合确认"
- 答题过程中提示会自动隐藏

## ⚙️ 技术实现

### 手势识别逻辑
```javascript
// 手势处理函数
function handleGesture(state) {
    if (!handSelectEnabled) return;
    
   const gesture = state.currentGesture;
    
    // 捏合 - 选择
    if (gesture === 'pinch' && state.pinchStrength > 0.7) {
        selectOption();
    }
    
    // 张开手掌 - 切换
    if (gesture === 'open_palm') {
        cycleOptions();
    }
    
    // 握拳 - 确认
    if (gesture === 'fist') {
        submitAnswer();
    }
}
```

### 启用/禁用机制
- 加载题目时自动启用手势选择
- 显示结果时自动禁用手势选择
- 避免误操作

## 🔧 灵敏度调节

如需调整手势灵敏度，修改以下参数：

```javascript
// 捏合阈值（0-1，越小越灵敏）
if (gesture === 'pinch' && state.pinchStrength > 0.7) {
    // 可以改为 0.5 更灵敏，或 0.9 更严格
}
```

## 🎨 视觉反馈

- **高亮边框** - 手掌悬停时卡片边框变亮
- **选项选中** - 选中的选项背景色变化
- **底部提示** - 实时显示手势操作提示
- **音效反馈** - 每个操作都有对应音效

## 🐛 注意事项

1. **首次使用**：需要等待摄像头启动和手势识别初始化
2. **光线要求**：确保使用环境光线充足
3. **摄像头角度**：手部需要在摄像头范围内清晰可见
4. **性能考虑**：手势识别会占用一定 CPU 资源
