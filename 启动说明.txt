🚀 启动步骤：
-------------------

方法一（推荐）- 使用主站点:
1. 在终端执行：npm install
2. 执行：npm start
3. 浏览器打开：http://localhost:8080/main-site.html

方法二 - 直接访问:
直接在浏览器中打开 main-site.html 文件


🎮 操作方式:
-------------------
键盘快捷键:
  ← / →  : 切换场景
  M      : 静音/取消静音
  H      : 显示/隐藏帮助
  ESC    : 关闭引导面板

手势操作:
  🖐️ 张开手掌 : 打开视图
  ✊ 握拳      : 关闭视图
  👌 捏合      : 缩放/拖拽

🔧 故障排除:
-------------------
问题：手势识别不工作
解决：检查摄像头权限，确保光线充足

问题：音频不播放
解决：与页面交互一次（点击任意处）

问题：场景加载慢
解决：检查网络连接，资源从 CDN 加载
