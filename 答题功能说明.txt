# 答题功能使用说明

## 新增功能概述

本项目已集成以下新功能：

1. **用户登录/注册系统** - 基于本地存储的用户管理
2. **选择题练习功能** - 包含 10 道关于胡焕庸线的题目
3. **错题重做功能** - 自动记录错题并支持针对性复习
4. **手势选择页面** - 在演示结束后提示用户选择练习模式

## 文件结构

### 新增文件：
- `login.html` - 登录/注册页面
- `quiz.html` - 选择题练习页面
- `review.html` - 错题复习页面
- `js/user-manager.js` - 用户管理器
- `js/quiz-manager.js` - 题库管理器
- `css/quiz.css` - 答题相关样式

### 修改文件：
- `main-site.html` - 添加了用户管理和题库管理模块引用
- `js/main-app.js` - 集成了答题选择提示功能

## 使用流程

### 1. 启动项目
```bash
npm start
```
或直接在浏览器中打开 `main-site.html`（推荐通过本地服务器访问）

### 2. 登录/注册
- 首次访问会自动跳转到登录页面
- 点击"立即注册"创建新账号
- 输入用户名和密码进行注册（密码至少 6 位）
- 注册成功后自动跳转回登录页面

### 3. 浏览学习
- 登录后可正常浏览所有讲解场景：
  1. 开篇展示（粒子地形）
  2. 地理认知（3D 地球）
  3. 时空演变（夜光数据）
  4. 工程建设（东数西算）
  5. 自然交互（手势演示）

### 4. 答题练习
当浏览完最后一个场景（自然交互）后，会自动弹出答题选择面板：

**选项说明：**
- 🆕 **新题练习** - 从题库随机抽取 5 题进行练习
- 📖 **错题巩固** - 重新做之前答错的题目
- ↩️ **继续浏览** - 关闭面板，继续查看其他内容

### 5. 答题操作
- 点击选项卡片选择答案
- 立即显示正确/错误反馈和解析
- 答对得 20 分，答错不得分
- 完成后显示统计结果（正确率、用时等）
- 答错的题目自动加入错题本

### 6. 错题复习
- 在主页可通过导航进入错题复习页面
- 查看所有错题列表
- 支持"开始复习"按钮进行错题重做
- 支持"清空错题"清除所有错题记录

## 测试建议

### 基础功能测试
1. 注册新账号并登录
2. 完成一次完整的新题练习
3. 故意答错几道题
4. 进入错题复习页面查看错题
5. 进行错题重做

### 集成测试
1. 从主页浏览到最后一个场景
2. 检查是否弹出答题选择面板
3. 分别测试三个选项的跳转功能
4. 验证答题结果是否正确保存到用户账号

### 边界测试
1. 未登录时尝试访问 quiz.html（应重定向到登录页）
2. 没有错题时点击"错题巩固"（应提示无错题）
3. 清空错题后再查看错题本
4. 重复答题多次验证统计准确性

## 注意事项

1. **数据存储**：所有数据存储在浏览器本地，清除浏览器缓存会丢失数据
2. **安全性**：密码未加密存储，仅用于演示目的
3. **跨域限制**：建议使用本地服务器运行（webpack dev server）
4. **浏览器兼容**：需要支持 ES6+ 的现代浏览器

## 技术支持

如有问题，请检查：
1. 浏览器控制台是否有错误信息
2. localStorage 是否正常写入
3. 所有 JS 文件是否正确加载
4. 网络连接是否正常（CDN 资源）
